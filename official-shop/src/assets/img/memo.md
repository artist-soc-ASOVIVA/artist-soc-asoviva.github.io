# ASOVIVA-Official-PortalSiteのimg要件定義書

## 1. 商品画像の命名規則

- 基本構成: `[イベント名]_[商品コード]_[グッズ名]_[番号].[拡張子]`
- 具体例: `ccf65_akusta_name_01.png`

## 商品コード（カテゴリ）定義一覧
プログラム内で識別するコードは以下の通りとする。

| カテゴリ名 | 商品コード | 命名例 |
| :--- | :--- | :--- |
| ステッカー | `sticker` | `ccf65_sticker_name_01.png` |
| ポストカード | `postcard` | `ccf65_postcard_name_01.png` |
| 缶バッジ | `badge` | `ccf65_badge_name_01.png` |
| 同人誌 | `book` | `ccf65_book_name_01.png` |
| ゲーム | `game` | `ccf65_game_name_01.png` |
| シール | `seal` | `ccf65_seal_name_01.png` |
| アクスタ | `akusta` | `ccf65_akusta_name_01.png` |
| アクキー | `akukey` | `ccf65_akukey_name_01.png` |
| その他 | `others` | `ccf65_others_name_01.png` |

##  バナーの命名規則
広告やイベントのバナーは商品画像と区別し、以下の規則で管理する。
- 基本構成: `[イベント名]_banner_[設置場所]_[番号].[拡張子]`
- 具体例（トップメインバナー）: `ccf65_banner_main_01.png`
- 具体例（サイドバーバナー）: `ccf65_banner_side_01.png`

## ファイル形式（拡張子）および容量制限

- WebP（ウェッピー）形式
- アップロード時の拡張子 :`.png`
- pngからwebpへ変換をする
